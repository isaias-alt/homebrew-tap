# isaias-alt Homebrew tap

Personal Homebrew tap for [isaias-alt](https://github.com/isaias-alt) tools.

## Installation

```bash
brew tap isaias-alt/tap
```

## Available formulas

### vexillum

CLI orchestrator for code agents.

```bash
brew install isaias-alt/tap/vexillum
```

Or after tapping:

```bash
brew tap isaias-alt/tap
brew install vexillum
```

For more info: [isaias-alt/vexillum repository](https://github.com/isaias-alt/vexillum)

## Updating

```bash
brew update
brew upgrade vexillum
```

## Uninstalling

```bash
brew uninstall vexillum
brew untap isaias-alt/tap
```
